# 个人 AI 交互偏好

## 沟通与语言

- 所有对话回复**必须**使用中文。
- 代码中的注释和文档字符串**必须**使用中文。
- 回复时如果包含代码块，**必须**标注语言（如 `python`、`rust`）。

## 工具使用习惯

- 在修改任何现有文件之前，**必须**先用 `Read` 工具查看该文件的完整内容。
- 在提出新方案前，优先用 `Grep` 或 `Glob` 搜索项目中是否有类似实现，避免重复造轮子。
- 修改 Python 文件后，主动运行 `black --target-version py313 python/` 格式化，确保 `black --check` 通过。

## 代码风格偏好

- Python 代码：优先使用 f-string 进行字符串格式化；类型注解**必须**完整。
- Python 代码：使用 `black` 格式化（目标版本 `py313`），行宽默认 88。
- Rust 代码：优先使用 `unwrap` 之外的错误处理方式（如 `?` 或 `expect`），但测试代码可放宽。

## 决策与澄清

- 如果我的请求存在歧义或缺少关键信息（如文件路径、函数名），请**先提问**，不要假设。
- 如果我的请求会导致性能严重下降或 API 破坏性变更，请先警告并给出替代方案。

## 可视化与界面调整偏好

- 优先通过调整参数（如 `xlim`/`ylim`/`margins`）来适配视觉布局，而非移动元素到边缘。
